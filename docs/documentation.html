Install the right file

  1. Unzip the complete marketplace download on your computer.
  2. In Shopify admin, open Online Store > Themes.
  3. Choose Add theme > Upload zip file.
  4. Upload Theme/Modeframe-1.0.0-theme.zip.
  5. Leave it unpublished while configuring and testing.

Do not upload the complete marketplace ZIP. It contains the manual and release files and is not an installable Shopify theme.

Confirm the purchase and licence

The licence selected on the marketplace at checkout controls use of Modeframe. Keep the marketplace receipt and purchase record. If your marketplace supplies a purchase code and the package contains ACTIVATE-LICENSE.txt, follow that channel-specific file.

Creative Market purchases currently use the Creative Market purchase record and do not require a separate Modeframe activation code. Never place a purchase code, receipt, or marketplace credential in theme settings, Custom Liquid, JavaScript, screenshots, or a public support request.

First setup

Add your logo, favicon, menus, products, collections, pages, blog, imagery, policies, market settings, social links, and footer content. Select real resources in every visible section; empty selectors intentionally show editor placeholders.

Review home, collection, product, search, cart, contact, account, policy, password, gift-card, and 404 templates on desktop and mobile. Complete a Shopify test order before launch, and keep a duplicate of the previous live theme as rollback.

Commerce setup

Products

Modeframe supports variant selectors and swatches, rich product media, unit pricing, quantity rules, inventory, pickup, accelerated checkout, gift-card recipients, recommendations, and app-created selling plans.

Collections and search

Configure filters and recommendations using Shopify Search & Discovery. Quick add appears only when no further product choice is required.

Cart and checkout

Choose drawer or page cart in Theme settings. Shopify remains responsible for prices, discounts, tax, shipping, payment, and checkout. Test both the cart interaction and checkout handoff.

Build editorial pages

The library includes Hero, Slideshow, Scroll Bridge, Motion Accents, Scrolling text, Rich text, Feature grid, Media with text, Featured collection/product, Collection list, Testimonials, Logo list, Featured blog, Video, Collapsible content, Newsletter, Call to action, and Custom Liquid.

Motion controls respect reduced-motion preferences. Check the fixed header over every major section and color treatment after changing media or colors.

Apps, forms, and security

Use app blocks for supported integrations. Selling plans require a compatible purchase-options app; markets, payments, pickup, instalments, and Follow on Shop depend on Shopify configuration and eligibility.

Never paste passwords, API keys, tokens, customer data, or payment information into theme settings, Custom Liquid, CSS, JavaScript, or a public support request.

Update without surprises

Install each update as a separate unpublished theme, transfer settings carefully, and retest. Shopify does not automatically merge every editor setting or custom code change. Keep the previous version until the update passes storefront and checkout checks.

Get support

First reproduce the issue in an unmodified Modeframe copy. Send the version, affected URL, browser/device, steps, expected result, actual result, and a screenshot where useful. Read the included FAQ and support policy for scope.
