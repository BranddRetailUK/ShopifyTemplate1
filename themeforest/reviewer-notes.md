# Modeframe 1.0.0 — reviewer notes

Thank you for reviewing Modeframe, a Shopify Online Store 2.0 theme.

## Installation

The submitted buyer archive is the outer package. The Shopify-installable file
is `Theme/Modeframe-1.0.0-theme.zip`. The outer archive also includes the HTML
manual, quick start, FAQ, support policy, credits, release notes, activation
instructions, and checksum.

## Technical notes

- Modeframe has one Shopify install preset and six internal global visual
  styles.
- The installed theme has no server dependency, tracking library, bundled app,
  minified vendor framework, or remote kill switch.
- Purchase activation is a separate server-side service used only to verify
  Envato support and update eligibility. It never controls storefront rendering
  or checkout and the Envato author token is never shipped to buyers.
- Theme Check, structure/provenance checks, static QA, unit tests, Playwright
  browser flows, and axe-core serious/critical accessibility checks are run on
  the release candidate. Evidence is recorded outside the buyer package.

## Live preview

Envato loads live previews inside an iframe, while Shopify storefronts return
security headers that prohibit third-party framing. The submitted preview URL
therefore serves an iframe-compatible Modeframe presentation page and opens the
exact Shopify demo in a new tab from an explicit buyer action. It has no
analytics cookies or competing purchase links.

## Assets and AI disclosure

The buyer ZIP contains no AI-generated imagery. Some listing presentation
concepts use OpenAI-generated, brand-neutral objects and are used only in the
item preview, which Envato's current AI-content policy permits. Exact Shopify
store screenshots are separately identified. No preview product, photo,
mockup, testimonial, or logo is represented as part of the buyer download.

## Activation timing

Envato purchase verification requires the final Envato item ID. If review is
performed before that identifier can be configured, the activation service
shows a configuration-pending message. This does not affect installation,
theme features, storefront availability, or review of the submitted files.
