# Modeframe Creative Market preview set

Run `node scripts/build-creative-market-assets.mjs` to rebuild the eight
1820x1214 PNG previews from the registered Modeframe concepts and exact live
store captures.

- Files 01 through 04 are AI-assisted presentation concepts.
- Files 05 through 08 are exact live-store captures or a composition of exact
  mobile captures.
- Preview media are marketplace collateral and are not included in the buyer
  download.
- Select **Yes** for Creative Market's generative-AI disclosure.
- Obtain commercial-rights approval for the captured demo catalogue and media
  before publication.
