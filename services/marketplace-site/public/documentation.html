Install Modeframe safely.

  1. Unzip the full ThemeForest download.
  2. In Shopify admin, open Online Store → Themes.
  3. Choose Add theme → Upload zip file.
  4. Upload only Theme/Modeframe-1.0.0-theme.zip.
  5. Leave it unpublished while you configure and test it.

Do not upload the complete ThemeForest ZIP. It contains the manual and buyer files and is not an installable Shopify theme.

Activate the purchase.

Visit the Modeframe activation service and enter the Envato purchase code plus the store’s permanent your-store.myshopify.com domain.

Activation confirms support and update eligibility for one store. It never remotely enables, disables, or changes the storefront. Never put a purchase code in theme settings, JavaScript, screenshots, or a public message.

Complete first setup.

Add the logo, favicon, menus, products, collections, pages, blog, imagery, policies, markets, social links, and footer content. Select real resources in visible sections; empty resource selectors intentionally show editor placeholders.

Review home, collection, product, search, cart, contact, account, policy, password, gift-card, and 404 pages on desktop and mobile. Complete a Shopify test order before launch and retain a duplicate of the previous live theme.

Choose a global style.

Paper, Ink, Signal, Electric, All light, and All dark restyle one Modeframe installation. They are not separate themes. Typography, widths, spacing, component radii, motion, search, cart behaviour, and social links live in Theme settings; sections add contextual layout and color controls.

Configure commerce.

Products

Modeframe supports variant selectors and swatches, product media, unit pricing, quantity rules, inventory, pickup, accelerated checkout, gift-card recipients, recommendations, and app-created selling plans.

Collections and search

Configure filters and recommendations with Shopify Search & Discovery. Quick add appears only when a product needs no further choice.

Cart and checkout

Choose drawer or page cart in Theme settings. Shopify remains responsible for prices, discounts, taxes, shipping, payments, and checkout.

Build editorial pages.

The section library includes Hero, Slideshow, Scroll Bridge, Motion Accents, Scrolling text, Rich text, Feature grid, Media with text, Featured collection/product, Collection list, Testimonials, Logo list, Featured blog, Video, Collapsible content, Newsletter, Call to action, and Custom Liquid.

Motion respects reduced-motion preferences. After changing media or colors, check fixed-header contrast over each major section.

Update and get support.

Install updates as a separate unpublished theme, transfer settings carefully, and retest. Shopify does not automatically merge every editor setting or custom-code change. Keep the previous version until the update passes storefront and checkout checks.

For help, reproduce the issue in an unmodified Modeframe copy and provide the version, affected URL, browser/device, steps, expected result, and actual result. Read the support policy before sending a request.
