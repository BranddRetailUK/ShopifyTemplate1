MODEFRAME 1.0.0
Modern Editorial Shopify Theme

PRE-RELEASE REVIEW NOTICE
This ThemeForest candidate is technically assembled but is not authorized for a
public sale until source/asset rights and the Modeframe name pass legal review,
the public demo is approved, and the manual QA gate is complete.

INSTALL
Open QUICK-START.txt, then upload only the ZIP inside the Theme folder to
Shopify. Do not upload the complete ThemeForest download.

DOCUMENTATION
Open Documentation/index.html in any modern browser. Markdown copies of the
manual, FAQ, and support policy are included for searchable plain text.

LICENSE
Read Licensing/ENVATO-LICENSE.txt and the Envato license shown at purchase.
Envato's mandatory license and buyer terms control the ThemeForest purchase.

ACTIVATION
Open ACTIVATE-LICENSE.txt after installing the theme. Activation binds the
Envato purchase to one permanent Shopify store for support and update
eligibility. It does not remotely enable or disable the storefront.

SUPPORT
Use the support URL shown on the ThemeForest item page or in the public
Modeframe support page.

Never share store passwords, API credentials, payment details, or customer data
inside a public support request.
